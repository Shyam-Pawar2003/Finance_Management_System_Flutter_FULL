## 📞 Quick Reference Cards

### Login Credentials Format
- Email: `any@example.com` (must contain @)
- Password: `minimum6chars` (minimum 6 characters)
- Role: Select from dropdown (User/Authority/Employee)

### File Structure
```
lib/
├── main.dart (routing)
├── models/ (data)
└── screens/ (8 screens)
```

### Important Routes
```
/login, /register, /home, /dashboard, /profile,
/company, /employee-tasks, /task-assignment
```

- Authority: Blue (#2196F3)
